# Drop the site photos in THIS folder (`public/images/`)

Use these exact filenames (spaces and capitalisation matter):

| Filename            | Where it appears                         |
| ------------------- | ---------------------------------------- |
| `outside2.jpeg`     | Hero background (top of the homepage)    |
| `resturaunt.jpg`    | Welcome / About section                  |
| `function room.jpg` | Functions section                        |
| `games room.jpg`    | Games Room section                       |
| `outside.jpg`       | Find Us / Contact section                |
| `logo.png`          | Header + footer crest (transparent PNG)  |

Tips:
- **Compress before uploading** (e.g. squoosh.app) — aim for < 400 KB each,
  and ~1600px wide is plenty. This keeps the site fast on phones.
- If `logo.png` is missing, the site quietly falls back to the text wordmark.
- Event photos added via the /admin editor are saved in `uploads/` automatically —
  you don't need to touch those by hand.
